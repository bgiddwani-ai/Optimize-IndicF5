# Third-party sources

This repository contains orchestration, serving wrappers and benchmark utilities.
It downloads the pinned AI4Bharat IndicF5 source during the image build instead of
vendoring that project. Upstream source and model terms remain applicable.

* IndicF5 source: https://github.com/AI4Bharat/IndicF5
* IndicF5 model and access/usage terms: https://huggingface.co/ai4bharat/IndicF5
* F5-TTS: https://github.com/SWivid/F5-TTS
* Vocos: https://github.com/gemelo-ai/vocos
* PyTorch: https://github.com/pytorch/pytorch
* Optimization reference: https://github.com/bgiddwani-ai/Optimize-sooktam2

The model card lists MIT licensing and requires accepting the access conditions.
Follow its voice-use terms. No model weights, compiled packages or access
credentials are distributed in this repository.
